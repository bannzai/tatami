macOS のタイル型ブラウザ

tmux ユーザーがブラウザで困っていたこと

分割は prefix + 1 打鍵で

マウスでタブをドラッグして並べる操作をやめる。ペインは tmux と同じ二分木で管理し、zoom・入れ替え・レイアウト切り替えまで同じキーで扱う。

どのサイト上でも効く

キーはアプリ側で捕捉する。Chrome 拡張方式のように、設定ページやストアの上でショートカットが効かなくなる穴を作らない。

設定はテキストファイル

~/.config/tatami/tatami.conf に .tmux.conf 風の文法でキーバインドと既定値を書く。dotfiles と一緒に管理できる。

パスワードマネージャー内蔵

拡張機能に頼らず、macOS のキーチェーンを金庫にした自前のストアを持つ。Chrome 互換 CSV で入出力でき、いつでも他のブラウザに戻れる。Safari など OS 全体からの自動入力にも対応予定。

キーバインド (既定値)

キー動作
prefix + " / %ペインを上下 / 左右に分割する
prefix + o / ;次のペイン / 直前のペインへ移動する
prefix + h j k l方向でペインを選ぶ
prefix + x / zペインを閉じる / zoom を切り替える
prefix + c / n / p / 0-9ウィンドウを作る / 移動する / 番号で選ぶ
prefix + /URL または検索語を入力する
prefix + a保存した資格情報を検索して入力する
prefix + :コマンドプロンプト (:open, :find, :bind, :source-file)
 
# ~/.config/tatami/tatami.conf
set -g prefix C-a
set -g search-engine "https://duckduckgo.com/?q="
bind | split-window -h
bind - split-window -v

使い始める

Tatami は開発中で、配布パッケージはまだありません。macOS 26 以上と Xcode 26.5 以上の環境で、ソースからビルドして /Applications に配置します。

make macos   # Release ビルドを /Applications/Tatami.app に配置する
make test    # ユニットテスト
