# プライバシーポリシー

bannzai（以下「提供者」といいます。）は、提供者の提供するサービス「Tatami」（以下「本サービス」といいます。）における、ユーザーについての個人情報を含む利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

## 収集する利用者情報および収集方法
本ポリシーにおいて、「利用者情報」とは、ユーザーの識別に係る情報、通信サービス上の行動履歴、その他ユーザーまたはユーザーの端末に関連して生成または蓄積された情報であって、本ポリシーに基づき提供者が収集するものを意味するものとします。

### ユーザーが入力・保存する情報（提供者のサーバーには送信されません）
本サービスでユーザーが入力・保存する閲覧履歴、ブックマーク、ペインやウィンドウの配置（セッション）、設定ファイルは、**ユーザーの端末内にのみ保存されます**。提供者のサーバーには送信されず、提供者はこれらの情報を収集・閲覧できません。

- 保存データのバックアップはユーザー自身の責任で行っていただきます。端末の変更・初期化・本アプリの削除によりデータが失われた場合、提供者は復旧できません

### ユーザーが閲覧するウェブサイトが収集する情報
本サービスはウェブブラウザであり、ユーザーがアクセスした各ウェブサイトは、そのウェブサイトの運営者の定めに従い Cookie その他の情報を収集することがあります。これらの情報の取扱いは各ウェブサイトの規約およびプライバシーポリシーに従うものとし、提供者は関与しません。

### 提供者が収集する情報
本サービスはアカウント登録を必要とせず、利用状況の計測（アナリティクス）やクラッシュレポートの送信も行いません。提供者がユーザーの個人情報をサーバーで収集・保管することはありません。ユーザーがメール等で問い合わせを行った場合に限り、その連絡先と問い合わせ内容を対応のために利用します。

## 利用目的
利用者情報の具体的な利用目的は以下のとおりです。

- 本サービスに関するご案内、お問い合わせ等への対応のため
- 本サービスに関する提供者の規約、ポリシー等に違反する行為に対する対応のため
- 本サービスに関する規約等の変更などを通知するため

## 第三者提供
提供者は、利用者情報のうち、個人情報については、あらかじめユーザーの同意を得ないで、第三者（日本国外にある者を含みます。）に提供しません。ただし、次に掲げる必要があり第三者（日本国外にある者を含みます。）に提供する場合はこの限りではありません。

- 提供者が利用目的の達成に必要な範囲内において個人情報の取扱いの全部または一部を委託する場合
- 合併その他の事由による事業の承継に伴って個人情報が提供される場合
- 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、ユーザーの同意を得ることによって当該事務の遂行に支障を及ぼすおそれがある場合
- その他、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の法令で認められる場合

## 個人情報の開示・訂正・利用停止・消去
提供者は、ユーザーから、個人情報保護法の定めに基づき個人情報の開示・訂正・利用停止・消去を求められたときは、ユーザーご本人からのご請求であることを確認の上で、遅滞なく対応します（当該個人情報が存在しないときにはその旨を通知いたします。）。ただし、個人情報保護法その他の法令により提供者が義務を負わない場合は、この限りではありません。

なお、端末内に保存されているデータは提供者が保有していないため、ユーザー自身が消去します。本アプリを削除しただけでは保存データは消えません。閲覧履歴・ブックマーク・セッション・設定は本アプリ内の消去操作または `~/Library/Application Support/Tatami/` の削除で消去してください。過去のバージョンの Password Manager 機能が macOS キーチェーンに保存した資格情報が残っている場合は、macOS の「キーチェーンアクセス」（iCloud キーチェーンの項目は同期先の端末にも反映されます）で消去してください。

## プライバシーポリシーの変更手続
提供者は、必要に応じて、本ポリシーを変更します。ただし、法令上ユーザーの同意が必要となるような本ポリシーの変更を行う場合、変更後の本ポリシーは、提供者所定の方法で変更に同意したユーザーに対してのみ適用されるものとします。なお、提供者は、本ポリシーを変更する場合には、変更後の本ポリシーの施行時期および内容を提供者の公開するウェブサイトでの表示その他の適切な方法により周知し、またはユーザーに通知します。
